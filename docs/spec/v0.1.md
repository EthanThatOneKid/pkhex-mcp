# pkhex-mcp v0.1 — Implementation-Ready Spec

* **Status:** Final — assembled from the [Wayfinder map](https://github.com/EthanThatOneKid/pkhex-mcp/issues/1); every section traces to a closed decision ticket or research branch.
* **Date:** 2026-08-22
* **Glossary:** `CONTEXT.md` · **Architecture:** ADR-0001, ADR-0002 (`docs/adr/`)

An AFK agent session should be able to implement this document end-to-end without hitting an unresolved decision.

---

## 1. Product summary & scope

pkhex-mcp reads live Pokémon Platinum state out of a running emulator and serves it over MCP so any AI chat client can reason about the player's run in real time. Read-only; Platinum-first; ships as a single Deno desktop binary with an embedded Inspector UI and a Chat Harness that points external clients at the MCP endpoint.

**In scope (v0.1):** live RAM ingestion → decode → in-memory state cache → Streamable HTTP + stdio MCP → OpenAPI/Swagger debug surface → vanilla webview Inspector + Chat Harness.
**Out of scope:** save write-back/editing; games beyond Platinum (D/P, HGSS); installer wrapping beyond `deno desktop --target` output; auto-updaters; static `.sav` analysis; embedded LLM chat plumbing. *(map: Out of scope)*

---

## 2. Architecture

Per ADR-0001/ADR-0002:

```
BizHawk (NDS core = melonDS) running Platinum
  └─ bridge/platinum-sync.lua        ← Sync producer
       │  HTTP POST /sync (form-encoded, every ≥500ms wall-clock)
       ▼
Deno ≥2.9 desktop app (deno desktop, CEF backend on Windows v0.1)
  ├─ Hono app via Denos.serve() (auto-bound loopback port)
  │   ├─ POST /sync   GET /state   GET /doc + /swagger   ALL /mcp
  ├─ Gen4 decoder (TypeScript owns decrypt/unshuffle/Add16)
  ├─ In-memory GameState cache (full-replace snapshots)
  └─ Embedded Inspector UI + Chat Harness (vanilla HTML/JS/CSS)
       ▼
External MCP clients (OpenWebUI, OpenCode, Claude Code/Desktop, Cursor, …)
```

## 3. Sync producer — `bridge/platinum-sync.lua`

Source decisions: [#10](https://github.com/EthanThatOneKid/pkhex-mcp/issues/10) · findings [`research/melonds-lua-api`](https://github.com/EthanThatOneKid/pkhex-mcp/blob/research/melonds-lua-api/docs/research/melonds-lua-api.md) · offsets [`research/platinum-memory-map`](https://github.com/EthanThatOneKid/pkhex-mcp/blob/research/platinum-memory-map/docs/research/platinum-memory-map.md)

- Runs inside **BizHawk 2.11.1+** NDS core; uses `event.onframeend`, `memory.read_u32_le(addr)` over Main RAM, `comm.httpPost`.
- **Cadence:** wall-clock accumulator inside the frame hook — POST when ≥500 ms real time elapsed since last send (pause-safe, turbo-proof). Frames ≠ time when unthrottled.
- **Retry policy:** on POST failure retry next tick — no backoff; log to console once per health-state change, never per failure. *(#8)*
- **Game gate:** read gamecode at `[0x02FFFE00]+0x0C`; proceed only on `CPUE` (Platinum US). Other codes → console warning + idle.
- **Reads** (all Pt-US verified):
  - Party container pointer `P1 = [0x02101D2C]`: partyBase = P1+0xD094, count byte P1+0xD090, slot stride **0xEC × 6**.
  - Save wrapper pointer `P2 = [0x021C0794]` (+0x14 = .sav General image): player name @+0x7C, TID/SID u32 @+0x8C, playtime h/m/s @+0x9E/A0/A1, map id u16 @+0x1294. Relation: P1 = P2 − 0xCFE0.
  - Per slot: copy raw 236 bytes + capture bit 0 of the flags word @0x04 (`partyDecrypted`) — the script does **not** decode anything *(#11)*.
- **Wire:** `POST http://127.0.0.1:<port>/sync`, `application/x-www-form-urlencoded`, one field `snapshot` whose value is the `SyncPayload` JSON string (§5).
- Repo ships the script plus illustrated setup docs (BizHawk install, BIOS×2 + firmware provisioning, loading the script). No auto-provisioning.

## 5. Frozen Zod contracts — `src/gen4/schemas.ts`

Source decision: [#7](https://github.com/EthanThatOneKid/pkhex-mcp/issues/7) (resolution comment holds the authoritative text).

```ts
// wire truth — value of the Sync's single form field (BizHawk posts it under
// its literal `payload` key; hand-rolled clients may use `snapshot` — both accepted)
SyncPayload = {
  trainerMeta: { tid: number /*u16*/, sid: number /*u16*/, playerName: string,
                 playtime: { hours: number, minutes: number, seconds: number },
                 mapId: number }
  slots: { bytes: string /*base64(236)*/, decryptedInPlace: boolean }[6]  // ALWAYS length 6
}

// presentation layer — GET /state, all MCP tool outputs, OpenAPI
GameState = {
  receivedAt: string            // server stamp, ISO-8601
  sync: { state: "live"|"stale"|"disconnected", ageMs: number }
  trainerMeta: SyncPayload["trainerMeta"] & { locationName: string | null }
  slots: (PartyMember | null)[6] // fixed length; index+1 = slot number; null = empty slot
}

PartyMember = {
  slot: number                  // 1..6
  pid: number                   // u32 identity
  speciesId: number; speciesName: string; types: string[]   // 1–2 entries
  level: number
  hpCur: number; hpMax: number
  statusCondition: null | "psn" | "brn" | "par" | "slp" | "frz"
  statusDetail: number | null   // sleep turns / toxic counter
  natureName: string            // derived PID % 25 at decode — never ingested
  heldItemId: number | null; itemName: string | null
  abilityName: string
  moves: ({ moveId: number, moveName: string, ppCur: number, ppMax: number } | null)[4]
  stats: { attack: number, defense: number, spAttack: number, spDefense: number, speed: number }
}
```

Empty party slots still ship raw bytes on the wire; emptiness is a *decode-time* verdict (species 0 / failed validation) surfacing as `null`.

## 6. Enrichment tables — `src/gen4/data/`

Generated lookup tables built by a script from public PokéAPI data, checked into source: species (id→name, types), moves (id→name, base PP), items (id→name), natures (index→name), abilities (id→name), Platinum map ids→names. The decoder joins these so every consumer surface serves readable names; no client needs its own tables.

## 7. Decoder — `src/gen4/crypto.ts` + `deserialize.ts`

Source decisions: [#11](https://github.com/EthanThatOneKid/pkhex-mcp/issues/11) · PK4 layout verified against PKHeX + pokeplatinum decomp *(research/platinum-memory-map)*.

Per slot, given `bytes` + `decryptedInPlace`:
1. PID = u32 @0x00; checksum word @0x06.
2. **Decrypt blocks** (skip XOR if `decryptedInPlace`): seed = checksum word; LCG `seed = 0x41C64E6D*seed + 0x6073`, XOR high-16 per u16 across bytes 0x08–0x87.
3. **Unshuffle**: block order = `(PID >> 13) & 31` mapping to [A,B,C,D].
4. **Battle-stats tail** @0x88–0xEB: XOR with PID-seeded LCG (same algorithm).
5. **Validate:** Add16 additive checksum recompute over decrypted bytes 0x08–0x87 must equal word @0x06.
6. Extract: species/item/nature-source fields from Block A; moves @BlockB+0x00–07, current PP @+0x08–0B (`ppMax` = base × PP-Up multiplier); level @0x8C, curHP @0x8E, maxHP @0x90, status @0x88; IVs @BlockB+0x10.
7. Species 0 or failed validation ⇒ empty slot (`null`) / torn-read handling (§8).

**Torn-read policy:** failed slots serve last-known-good values invisibly; degradation persists >5 s on a card ⇒ amber tint. Degraded-slot counts live only on the debug surface, never in MCP vocabulary.

## 8. State cache & sync health — `src/state/game-state.ts`

Source decision: [#8](https://github.com/EthanThatOneKid/pkhex-mcp/issues/8).

- Memory-only singleton; each valid `POST /sync` is an idempotent **full-replace**, stamped `receivedAt`.
- **Sync health:** `live` ≤2 s · `stale` ≤30 s · `disconnected` >30 s or none since process start.
- Surfaces: UI strip 🟢 `LIVE` / 🟡 `STALE · Ns` counting up / 🔴 `DISCONNECTED — start your emulator with the bridge script running`; polling never gives up (500 ms forever). Data tools always return last-known data with a `sync:{state, ageMs}` block; hard error only when zero snapshots ever received. `get_sync_status` = `{state, ageMs|null, receivedAt|null}`.
- App restart self-heals within one producer tick; no persistence layer.

## 9. HTTP routes & security

- `POST /sync` — validates `SyncPayload` via Zod; rejects malformed payloads with 400 (producer logs per state change).
- `GET /state` — current `GameState`.
- `GET /doc` (OpenAPI JSON) + `GET /swagger` (interactive debug UI) via `@hono/zod-openapi`.
- `ALL /mcp` — `@hono/mcp` `StreamableHTTPTransport`; never redirect `/mcp` (drops session ids).
- `/` — embedded Inspector UI.
- **Bind loopback only.** Host allowlist: `127.0.0.1:*`, `localhost:*`, `[::1]:*`, `host.docker.internal`; Origin: missing allowed (non-browser clients), non-loopback rejected. No auth tokens v0.1. Advertise literal `127.0.0.1:` URLs (localhost may resolve `::1`). *(#4 client matrix)*

Dev default port when not under `deno desktop`: **8941**. Under `deno desktop`, honor runtime-injected `DENO_SERVE_ADDRESS` (always loopback).

## 10. MCP surface

Server name `pkhex-mcp`, version `0.1.0`. Tools return contract types verbatim *(#7)*:

- `get_party()` → `(PartyMember|null)[6]`
- `get_game_state()` → `GameState`
- `get_sync_status()` → `{state, ageMs, receivedAt}`
- Derived helpers: `get_pokemon_by_slot(slot: 1..6)`, `find_party_member_by_species(nameOrId: string|number)`

No resources/prompts in v0.1. Transports: Streamable HTTP at `/mcp`; `--stdio` flag runs `StdioServerTransport` on stdin/stdout with no HTTP serving.

**Client snippets** (authoritative texts in [`research/mcp-client-matrix`](https://github.com/EthanThatOneKid/pkhex-mcp/blob/research/mcp-client-matrix/docs/research/mcp-client-matrix.md)): OpenWebUI ≥0.6.31 admin form · OpenCode `type:"remote"` · Claude Code `claude mcp add --transport http pkhex http://127.0.0.1:<port>/mcp` · Cursor `mcpServers.url` · VS Code `.vscode/mcp.json` top-level `servers` · Gemini CLI `httpUrl`. Claude Desktop: recommend the `mcp-remote` bridge (its native HTTP entries are version-flaky, config-deletion bug #37286); Custom Connectors are unusable (cloud egress).

## 11. Inspector UI — vanilla HTML/JS/CSS served by Deno.serve()

Source decision: [#6](https://github.com/EthanThatOneKid/pkhex-mcp/issues/6) (Variant A) · artifact [`prototype/inspector-cards`](https://github.com/EthanThatOneKid/pkhex-mcp/blob/prototype/inspector-cards/inspector-card-layout.html).

- Trainer strip pinned top: name · TID/SID · playtime · location · sync-health indicator.
- **3×2 grid of uniform stat cards**: header (name, type chips, level) → HP bar with cur/max + status chip inline → meta line (nature · held item · ability) → two-column moves list with `ppCur/ppMax` → stats row (attack…speed).
- Polls `GET /state` every 500 ms, forever. Changed values flash amber; **tabular numerals** keep layout from jumping.
- **Chat Harness** docks as a right-hand panel: copyable client-config snippet pointing external clients at `/mcp`; no input box.

## 12. Packaging & distribution

Source: [#5](https://github.com/EthanThatOneKid/pkhex-mcp/issues/5) · [`research/deno-desktop-packaging`](https://github.com/EthanThatOneKid/pkhex-mcp/blob/research/deno-desktop-packaging/docs/research/deno-desktop-packaging.md).

- `deno.json` `desktop` block holds metadata/backend/output; window options are **`Deno.BrowserWindow` constructor args** (title, fixed size ~1024×720).
- Backend: **CEF for v0.1 Windows** (webview regressions #35645/#36515/#36500 open); OS-webview backend stays one config flip away — revisit when those close. DevTools are CEF-only.
- Build: `deno desktop --compress=xz --output ./dist/pkhex-mcp.msi --target x86_64-pc-windows-msvc main.ts` cross-compiles from any host; `.dmg` requires a macOS host; five targets exist (win-x64, mac x64/arm64, linux x64/arm64); tri-OS emitted, Windows tested-first tier. Auto-update is unix-only — out of scope regardless.
- **Deferred to implementation discretion** (does not gate any decision): artifact naming/version strings, CI release pipeline shape, icons/signing, error-report endpoint.

## 13. Test strategy

- **Synthetic byte fixtures** built field-by-field in test code (valid encrypted+shuffled PK4 member with correct Add16 checksum, empty-slot bytes, torn-read variants) — no copyrighted game data committed.
- **Property round-trip tests:** encoder→decoder for randomized members.
- Route tests via Hono `app.request()`; staleness transitions via injected clock; MCP handshake smoke over both transports.
- Optional gitignored local hook: real-save/RAM smoke check when BizHawk + Platinum present.

## 14. Region note

v0.1 targets **Platinum US** (`CPUE`) — the only build verified end-to-end. The gamecode gate refuses other regions with a clear message rather than guessing addresses (JP/EUR pointer slots unverified; EU code addresses already differ +0xA4). Extending regions touches only §3 constants and decoder anchors.
